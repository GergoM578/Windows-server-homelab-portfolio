# DFS-replication-homelab
## Project Overview

This project demonstrates how to configure DFS Replication between a parent domain and a child domain in Active Directory.

Parent Domain:

London.local

Child Domain:

Wembley.London.local

## Technologies

- Windows Server 2022
- Active Directory
- DFS Namespace
- DFS Replication
- DNS
- Group Policy
- PowerShell

 ## Environment

2 Virtual Machines

WServer1
London.local

WServer4
Wembley.London.local

## Objectives

- Configure DFS Replication
- Configure DFS Namespace
- Test replication
- Troubleshoot firewall issues

## Result

Replication works successfully between both domains.
